# Public security-reference note: CWE-787

- **Title:** CWE-787: Out-of-bounds Write
- **Publisher:** MITRE
- **Source:** https://cwe.mitre.org/data/definitions/787.html
- **Retrieved:** 2026-11-22
- **Use in VulnGenome Lite:** Classification vocabulary and general remediation context only.

MITRE describes CWE-787 as a write before or after the intended buffer. Its implementation guidance includes checking bounds when a loop writes through a buffer. This note is a paraphrase for local retrieval, not a vulnerability finding about either uploaded binary.

The selected CWE entry can help explain a confirmed, evidence-backed out-of-bounds write. It cannot establish that a binary has that weakness, that a patch is correct, or that an inconclusive analysis is safe. Those statements must come from the current binary-derived engine record and remain scoped to its evidence.
