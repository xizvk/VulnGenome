# Research-artifact report (work in progress)

## Hypothesis

Evidence-grounded typed invariants, target-specific semantic roles, and solver checking may improve transfer over function similarity or unconstrained language-model reasoning. This remains an untested research hypothesis.

## Implemented technique

The prototype has strict expression/invariant records, finite-width SMT-LIB generation, a Z3 result policy, angr CFG/VEX extraction when its dependencies import, exact-symbol patch matching, and an angr symbolic call-site adapter. The controlled C pair places one unsigned argument at a named sink and varies whether a `length <= 16` guard dominates that call.
